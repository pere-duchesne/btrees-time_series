# Argentine Calendar (`data/argentine_calendar.R`)

This module builds an **enriched calendar** for Argentina that serves as the
foundation for regression features in time-series models (decision trees,
B-trees applied to forecasting, etc.).

The goal is to have, for every day in a given range of years, a set of
time-based variables ready to be used as predictors: seasonality, day of week,
fraction of the year, holidays, etc.

## Contents

The script `data/argentine_calendar.R` exposes four functions:

| Function | Description |
|---|---|
| `make_days(years)` | Builds a `data.frame` with one row per day for each requested year and derives calendar features. |
| `retrieve_holidays(years)` | Downloads national holidays from the public API at [argentinadatos.com](https://argentinadatos.com/). |
| `wrapper(years)` | Orchestrates the above: builds the calendar, joins holidays, returns JSON. |
| `save_calendar(years)` | Calls `wrapper()` and persists the result to `calendar.json`. |

## Features generated by `make_days()`

For each date the following are computed:

- `date` — the date (`Date` class).
- `year`, `month`, `day_of_month` — basic components.
- `week_day` — day of the week (1 = Monday … 7 = Sunday).
- `year_day` — day of the year (1–366).
- `month_start`, `month_end` — first and last day of the month.
- `days_in_month` — number of days in the month.
- `week` — ISO week.
- `quarter` — quarter (1–4).
- `year_month` — numeric identifier `YYYYMM`.
- `month_id` — sequential month index since the start of the range.
- `day_fraction` — position of the day within the year (0–1), useful for continuous seasonality.
- `type` — **1 if holiday, 0 otherwise** (added in the `wrapper`).

## Usage

From R:

```r
source("data/argentine_calendar.R")

# Generate and save calendar.json for the given years
save_calendar(c(2023, 2024, 2025))

# Later read
library(jsonlite)
calendar <- read_json("calendar.json")
